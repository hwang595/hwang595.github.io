Benchmarking gene embeddings

How much can a gene embedding predict when its input already contains clues to the answer? GeneProv compares text, sequence and expression models across four tasks, tracking the source of each input.

Two ways to evaluate a model

Choose a track based on whether you can change the model’s input text.

Benchmark design →
Track O

Bring a representation

Compare an existing embedding with other models. Report gene coverage, the origin of any text it embeds, and whether text entered its training.

Open-track instructions →
Track F

Fix the text, compare encoders

Encode the same GenePT corpus twice. Removing Alliance-generated summaries in one version measures how much each encoder’s GO score depends on those summaries.
