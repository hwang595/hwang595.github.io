Benchmark file catalog

The research repository is private. The gene-level task inputs, scripts and provenance tables listed below are not hosted on this site. A Zenodo deposit is in preparation; it has no public DOI yet. For questions about access, contact the corresponding author.

Provenance tables

provenance_human_protein_coding.tsv has one row per gene: symbol, entrez_id, exposure (PubMed articles linked in gene2pubmed, counting articles with at most 20 genes), exposure_bin, genept_key, genept_2023_source and genept_2023_tag_date (the tag in GenePT's October-2023 text), genept_2024_template_flag (detector on GenePT's untagged 2024 text) and ncbi_2026_source (tag of the NCBI Gene summary on 6 October 2026). Source values: alliance (generated from GO), refseq (curated), other, none, absent. provenance_genept_keys.tsv carries the same flags for all 33,703 GenePT keys.

Template detector

Python standard library only. It reads the [provided by ...] tag when present and otherwise flags a summary whose first sentence starts with an Alliance template phrase; on GenePT's 2024 text against the 2023 tags: precision 1.000 and recall 0.999 for the revised detector. The original template list had recall 0.997.

from gene_text_audit import is_generated, strip_generated
summary_filtered = {gene: strip_generated(text) for gene, text in summaries.items()}

Metadata correction of 25 October 2026

The exposure column of both released gene tables now contains the filtered publication count that defines exposure_bin; the original export had written the unfiltered count into it (19,141 values changed; bins, folds, labels and every stored score were unchanged). Before-and-after checksums and a regression check are in review_2026-10-25/ of the repository.
